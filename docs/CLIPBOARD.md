# 手动复制到 X Article

## 为什么整段复制没有带走表格

预览中的表格和代码已经转成 PNG，通过本站的 Blob URL 显示。浏览器选择区域的富文本复制不能可靠地把这些本地图片上传到 X。标题、正文文字和列表可以进入粘贴结果，不代表图片也被传递。

## 正确操作

1. 预览上方“复制标题” → X 顶部“添加标题”栏。
2. “复制正文” → X 正文编辑区域。标题和封面不会混入正文，图片位置保留为明确的 `[图片 N：…，请单独插入]` 提示。
3. 找到本站对应图片，点击“复制图片”，再到 X 对应位置粘贴。此按钮写入真实 `image/png`，不是 `blob:` 地址或 HTML 图片引用。
4. 如果 X 没有接受图片粘贴，点击“下载 PNG”，在 X 使用图片上传入口插入。长表和代码分片需要逐张处理。
5. 删除正文中相应的位置提示，检查全部图片、链接、标题和列表，再人工发布。

复制成功只表示本站已写入剪贴板。本站无法据此知道 X 是否接收、是否保存或是否发布；不会自动操作 X。

## 降级与安全

- 浏览器不支持富文本时，明确提示“正文纯文本已复制”，需要在 X 检查格式。
- 图片复制不受支持或权限被拒绝时，提示下载，不把文本地址当作图片成功复制。
- HTML 由目标块白名单生成；不复制应用 UI、不执行源码 HTML，不传出本地 Blob URL。
- PNG 剪贴板数据使用 Promise 保持用户手势，异步读取图片前就调用剪贴板 API。
- 复制源文不要求先上传或登录，不会改变文章 revision 或源文本。

## 0.1.1 验证记录

在用户已打开的 HTTP 写作台中，使用示例文稿做了真实按钮点击及本地隔离页粘贴测试，未操作 X 页面：

| 操作 | 观察结果 |
|---|---|
| 复制正文 → 隔离区粘贴 | 同时收到 text/html、text/plain；包含 H2 与图片位置提示；不含文章标题或 blob 地址 |
| 复制标题 → 隔离区粘贴 | 仅收到标题的 text/plain |
| 复制表格图片 → 隔离区粘贴 | 收到 image/png 文件，29,675 字节，可解码为 1440 × 396 图像 |
| 下载 PNG | 点击后生成下载并给出提示；自动下载事件未取得文件落盘回执，不宣称已保存到磁盘 |
| 重复打开同一文稿 | 修复后预览和图片控件仍存在 |
| 深浅主题 | 两种主题下的按钮与状态可见；PNG 保留原色 |

本地测试页不联网、不执行粘贴 HTML，也不保存文稿。用户提供的 X 账号截图不提交到仓库。38 个单元测试通过；生产 Worker 回归和构建检查通过。

证据边界：尚未验证 X 对新版图片粘贴的最终处理，也没有覆盖所有浏览器或发布真实文章。整个项目仍是私有预览版。
