# ADR 001 · 服务器分发，浏览器本地保存

日期：2026-08-31。状态：按用户明确部署要求实施。

原 PRD 的固定 loopback 启动器是桌面离线分发方案。用户随后明确要求 Docker 部署到服务器，并使用 xeditor.acks.com.cn，因此首个部署版本采用 HTTPS 静态 Web 应用。

保留 React / TypeScript / Vite、CodeMirror、Dexie 与独立转换器；容器只提供静态文件。首次访问在线，资源缓存完成后离线可用。不会因为“部署到服务器”而自动增加云稿件、账号系统、AI 服务或上传接口。

这改变了“首次安装后断网冷启动”的具体交付方式：网站模式的首次访问仍需联网。部署版本不宣称满足未实现的桌面启动器分发要求。Node.js 24 用于构建，不作为首版线上 API 运行时。

用户已选择方案 1 和深浅主题。界面切换主题只改变 CSS tokens，不改文章源文或导出图片内容。图像生成稿属于视觉基线；正式 UI 的保存、导出、错误与版本数据必须真实。

X OAuth / 草稿桥仍需 V2 的独立安全设计与真实账户验证。服务器模式不能直接沿用桌面系统 Keychain；如后续增加多用户授权，需要额外的身份隔离、会话、令牌加密与备份设计，本次不擅自启用。
