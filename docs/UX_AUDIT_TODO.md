# UX / UI 审计问题解决任务列表

来源：2026-09-22 第三方视角产品审计。状态以代码、测试和浏览器复验为准。

## P1 — 公开体验高影响

- [x] **P1-01 顶部操作区拥挤与裁切**
  - Header 合并手动/直接发布为单一“发布”主入口。
  - 账号、发布、导出在中等宽度切换为紧凑按钮。
  - Header context 不再逐字换行。
- [x] **P1-02 中等宽度预览裁切**
  - 源文/预览单面板断点提前到 1270px。
  - 单面板预览使用可读宽度居中。
- [x] **P1-03 Service Worker 更新反馈延迟**
  - 注册后主动执行 `registration.update()`。
  - 每 60 秒复查 waiting worker。
  - 更新提示改为居中且限制在视口内。
- [x] **P1-04 完整资源包主按钮位于首屏之外**
  - 导出主操作固定在弹窗底部。
  - 次级格式保留在主操作上方。
- [x] **P1-05 英文界面动态标签仍为中文**
  - 图片序号、图片类型、预览署名和图片 alt 接入 i18n。
- [x] **P1-06 Header 多个同权重 CTA**
  - Header 只保留一个“发布”主按钮。
  - 发布方式在选择弹窗内分流。

## P2 — 可访问性与理解成本

- [ ] **P2-01 Markdown 工具栏发现性不足**
  - 设计常用工具区、分组菜单和 More 菜单。
  - 保留键盘快捷键与完整可访问名称。
- [x] **P2-02 主题、语言和账号页签语义不准确**
  - 主题/语言改为 `radiogroup/radio`。
  - 登录/注册改为 `tablist/tab/tabpanel`。
- [~] **P2-03 弹窗焦点管理**
  - 登录/注册初始焦点改为用户名。
  - 待完成：发布、校验、导出弹窗的任务相关初始焦点回归。
- [x] **P2-04 手动发布步骤编号重复朗读**
  - 移除原生 marker 与文本计数器的重复组合。
  - 视觉编号改为无可访问文本的背景图，读屏只朗读步骤内容。
- [x] **P2-05 校验状态图标语义混淆**
  - info、warning、error、success 使用不同图标和颜色。
- [ ] **P2-06 小字号说明文字对比风险**
  - 测量浅色/深色模式对比度。
  - 关键说明不低于 13–14px。
- [ ] **P2-07 邀请码来源与密码辅助不足**
  - 增加邀请码获取说明。
  - 增加显示密码、Caps Lock 和规则反馈。
- [ ] **P2-08 发布门槛缺少手动发布退路**
  - 在未登录直发门槛增加“改用手动发布”。

## P3 — 长期使用效率

- [ ] 文稿排序：最近编辑、标题、创建时间。
- [ ] 文稿固定与完整标题 tooltip。
- [ ] 低频 Markdown 工具的分组收纳。
- [ ] 管理员邀请码列表、撤销未使用邀请码、审计记录。
- [ ] 建立 320、375、768、1024、1280、1440、1920px 截图回归矩阵。
- [ ] 执行 VoiceOver、完整键盘回路、200% 缩放和 axe 自动扫描。

## 验收门槛

- P1 必须全部通过桌面、中等宽度、中英双语和深浅模式截图回归。
- P2 每项必须包含键盘或辅助树证据。
- 不因 UI 修复改变 Markdown 真源、IndexedDB 文稿、OAuth token 或发布结构。
- 生产部署继续保留旧镜像、旧发行目录和回滚路径。
