# UX 回归与无障碍检查

仓库提供可重复执行的浏览器回归命令：

```bash
pnpm audit:ux
```

该命令先生成生产构建，再使用本机 Chrome/Chromium 执行以下检查：

- 生成 320、375、768、1024、1280、1440、1920px 七档截图；
- 检查页面是否产生横向溢出；
- 在每档尺寸运行 WCAG 2 A/AA 与 WCAG 2.1 A/AA axe 扫描；
- 记录主界面键盘 Tab 顺序与可见焦点；
- 检查发布弹窗初始焦点、焦点循环和 Escape 关闭；
- 使用 720 CSS 像素视口和 2 倍设备比例检查等效 200% 缩放布局。

结果保存在 `.local/ux-regression/<时间戳>/`，包含 PNG、`report.json` 和 `REPORT.md`。该目录不提交到 Git。

如果 Chrome 不在常见安装路径，可以指定：

```bash
CHROME_PATH=/path/to/chrome pnpm audit:ux
```

## VoiceOver 手动验收

自动辅助树和 axe 不能替代 macOS VoiceOver。正式发布前应在生产构建上完成以下手动检查：

1. 从页面顶部依次朗读主题、语言、校验、账号、发布和导出；
2. 确认文稿排序、文稿标题、固定按钮和编辑器都有独立名称；
3. 展开“更多格式”，确认每个 SVG 工具按钮均朗读用途；
4. 打开发布、校验、导出和账号弹窗，确认初始焦点与焦点循环；
5. 确认 Escape 关闭弹窗后回到触发按钮；
6. 检查中英文和深浅模式各一次。

开启或关闭 VoiceOver 会改变 macOS 辅助功能状态，应由测试者明确授权后执行。
